Model Context Protocol (MCP) Endpoints

Ghana-MCP is an autonomous MCP server designed for LLMs (Claude Desktop, Cursor, LangChain). Connect your agent via these endpoints:

1. Claude Desktop (stdio mode)
{ "mcpServers": { "ghana-mcp": { "command": "python3", "args": ["-m", "ghana_mcp.server", "--stdio"] } } }
2. Remote SSE Endpoint (Cloudflare Protected)
https://mcp.ghanaopenai.org/mcp/sse
3. Direct REST Search API
curl -X POST https://mcp.ghanaopenai.org/api/search \ -H "Content-Type: application/json" \ -d '{"text": "who is the current president of ghana", "top_k": 50}'
