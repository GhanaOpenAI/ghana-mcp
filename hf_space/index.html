Connect Your LLM to Ghana-MCP

Use Ghana-MCP directly in Claude Desktop, Cursor, or your custom LLM application via Model Context Protocol (MCP).

Claude Desktop Configuration

Add to ~/Library/Application Support/Claude/claude_desktop_config.json (macOS) or %APPDATA%\Claude\claude_desktop_config.json (Windows):

{ "mcpServers": { "ghana-mcp": { "command": "python3", "args": ["-m", "ghana_mcp.server", "--stdio"] } } }
